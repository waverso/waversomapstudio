## Features
- **Scene:** Objects, actors, vehicles, pickups, building removals and 3D areas.
- **Materials:** Replace textures, recolor surfaces and add text to objects.
- **Races:** Checkpoints, circuits, laps and instant in-game testing.
- **World editing:** Select, inspect, clone and delete native game entities.
- **Layouts:** Generate grids, loops and repeated structures along editable curves.
- **Animations:** Preview actor animations and moving objects directly in the scene.
- **Browsers:** Objects, textures, vehicles, skins and animations, with previews, filters and sorting.
- **Tools:** Grid and ground snapping, surface alignment, duplicate detection and clone offsets.
- **Navigation:** Fly, pan, orbit and focus the selection, teleport to locations and save viewpoints.
- **View:** Toggle interiors, colliders and selection bounds, and preview different times and weather.
- **Pawn:** Import code from the clipboard and export for SA-MP/open.mp, with configurable export options.

## Requirements
- Install [ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/latest). Skip if you already have it.
- SA-MP client **0.3.7 R1**, **0.3.7 R5**, or **0.3.DL**. Other versions are not supported.

## Installation
1. [Download](../../releases/latest) the `.asi` file.
2. Copy the `.asi` file to the game's root directory.
3. Start the game and press **F4** to open the editor.

## Recommended
Optional, but recommended: install [SilentPatch](https://github.com/CookiePLMonster/SilentPatch/releases/latest/download/SilentPatchSA.zip) and [Windowed Mode](https://github.com/ThirteenAG/III.VC.SA.WindowedMode/releases/latest/download/III.VC.SA.WindowedMode.zip) in the game's root directory.
